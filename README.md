# Jokenpo

Jogo de **Pedra, Papel e Tesoura** desenvolvido com **HTML**, **CSS** e **JavaScript**, com escolha automática da máquina, placar e feedback visual durante as rodadas.

## Visão geral

O jogador escolhe entre Pedra, Papel ou Tesoura. A máquina faz uma escolha aleatória, o resultado da rodada é calculado e o placar é atualizado automaticamente.

## Funcionalidades

- Escolha entre Pedra, Papel e Tesoura
- Jogada aleatória da máquina
- Exibição da escolha do jogador e da máquina
- Placar para jogador e máquina
- Animação de pulso quando uma pontuação aumenta
- Layout responsivo para telas menores

## Tecnologias utilizadas

**HTML5** | **CSS3** | **JavaScript**

## Conceitos praticados

- Manipulação do DOM
- Eventos de clique
- Geração de escolha aleatória
- Estruturas condicionais
- Atualização de placar em tempo real
- Animações com CSS

## Como executar

```bash

cd Jokenpo
```

Depois, abra o arquivo `index.html` no navegador.

## Regras do jogo

- Pedra ganha de Tesoura
- Tesoura ganha de Papel
- Papel ganha de Pedra
- Escolhas iguais resultam em empate
